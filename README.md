# Portafolio

Demo websites built as portfolio samples. All brands, names, contact details and testimonials are fictional.

- `contable/` — Landing page for a fictional accounting firm (Norte & Asociados).
- `salud/` — Editorial health portal (Claro Salud).
- `clinica/` — Multi-page conversion site for a fictional clinic (Alineo): home, plans, procedure, stories, clinics and blog pages, with a scripted AI advisor and WhatsApp/call CTAs.

Plain HTML, CSS and JavaScript, no build step. Published with GitHub Pages.
